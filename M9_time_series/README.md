# Module 9 – Time Series Analysis and Forecasting

This project was completed using IBM SPSS Statistics as part of UCI Data Science coursework.

## Topics Covered
- Time series analysis
- Sequence chart analysis
- Trend identification
- First-order differencing
- Second-order differencing
- Stationarity assessment
- ARIMA modeling
- Residual diagnostics
- Forecasting analysis

## Skills Demonstrated
- Time series modeling
- Statistical forecasting
- Predictive analytics
- SPSS time series analysis
- Model interpretation
- Quantitative analysis
- Data visualization

## Dataset
This analysis used the Broadband Dataset provided for UCI Data Science coursework. The project focused on broadband subscriber growth in Market 16 and applied time series techniques to model historical trends and generate forecasts.

## Key Findings
- The original subscriber series showed a strong upward trend over time.
- Second-order differencing was selected to achieve stationarity.
- An ARIMA(1,2,1) model was developed for forecasting.
- The model achieved a Mean Absolute Percentage Error (MAPE) of less than 1%, indicating strong predictive performance.
- Residual diagnostics suggested no significant autocorrelation remained in the model residuals.
- Forecast results indicated continued growth in broadband subscribers for Market 16.
