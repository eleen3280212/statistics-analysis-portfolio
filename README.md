# Statistics Analysis Portfolio

This repository contains statistical analysis projects completed using IBM SPSS Statistics as part of UCI Data Science coursework.

## Projects

### Module 1 – Descriptive Statistics, Probability, and Inferential Statistics
- Descriptive statistics
- Histograms
- Data visualization

### Module 2 – Chi-Square Test of Independence
- Categorical data analysis
- Hypothesis testing

### Module 3 – Independent Samples t-Test and Group Comparison
- Mean comparison
- Inferential statistics

### Module 4 – Pearson Correlation Analysis
- Correlation analysis
- Relationship assessment

### Module 5 – One-Way ANOVA and Multiple Group Comparison
- Group mean comparison
- Post hoc analysis

### Module 6 – Two-Way ANOVA and Interaction Effects
- Main effects
- Interaction analysis

### Module 7 – Linear Regression Analysis
- Predictive modeling
- Regression analysis

### Module 8 – Decision Tree Classification and Model Validation
- Machine learning
- Classification modeling

### Module 9 – Time Series Analysis and Forecasting
- ARIMA modeling
- Forecasting

## Software Used

- IBM SPSS Statistics

## Dataset

Most projects utilize data from the General Social Survey (GSS) 2018 dataset.

Source:
https://gss.norc.org/

Exceptions:

- Module 9 – Time Series Analysis and Forecasting
  - Uses the Broadband dataset included within the module folder.
