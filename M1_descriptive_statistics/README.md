# Module 1 – Descriptive Statistics, Probability, and Inferential Statistics

This project was completed using IBM SPSS Statistics as part of UCI Data Science coursework.

## Topics Covered
- Descriptive statistics
- Histograms
- Pie charts
- Frequency analysis
- Z-score analysis
- Outlier detection

## Skills Demonstrated
- Statistical interpretation
- Data visualization
- SPSS reporting
- Quantitative analysis
  
## Dataset
This analysis used data from the General Social Survey (GSS) 2018 dataset, a nationally representative survey widely used in social science research.
