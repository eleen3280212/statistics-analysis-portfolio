# Module 2 – Chi-Square Test of Independence

This project was completed using IBM SPSS Statistics as part of UCI Data Science coursework.

## Research Objective
This analysis examined whether there is a statistically significant relationship between respondents’ race and their perception of family demands using a Chi-Square Test of Independence.

## Statistical Methods
- Chi-Square Test of Independence
- Post-hoc analysis
- Crosstabulation analysis
- Clustered bar chart visualization
- Assumption testing

## Topics Covered
- Categorical variable analysis
- Hypothesis testing
- Statistical significance
- Expected cell counts
- Interpretation of p-values
- Group comparison analysis

## Skills Demonstrated
- Statistical interpretation
- SPSS data analysis
- Quantitative reasoning
- Data visualization
- Inferential statistics
- Research reporting

## Key Findings
The analysis found a statistically significant relationship between race and perceived family demands. White respondents were more likely to report lower levels of family demands, while Black and Other respondents were more likely to report experiencing family demands at least sometimes.

## Dataset
This project used the General Social Survey (GSS) 2018 dataset located in the `/datasets` directory.
